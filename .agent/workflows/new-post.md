---

To create a new blog post, use specify the title:

// turbo
1. Run the blog post creation script:
```bash
scripts/blog post create "Your Post Title"
```

2. The script will create a new directory and file at `content/posts/YYYY/MM/your-post-title/index.md`.

3. Edit the frontmatter and content of the newly created file.
