---

To create a new blog post, specify the title:

// turbo
1. Run the blog post creation task:
```bash
task post:create -- "Your Post Title"
```

2. The task will create a new file at `content/posts/YYYY/MM/your-post-title/index.md`.

3. Edit the frontmatter and content of the newly created file.
